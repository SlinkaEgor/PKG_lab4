# Лабораторная работа №4 по ПКГ

Растеризация отрезков, окружности и эллипса на виртуальной сетке.

- **Построение** — шесть алгоритмов, примеры и координатная сетка. Предпросмотр обновляется при вводе, а кнопка «Построить» добавляет фигуру к уже построенным.
- **Бенчмарк** — замеры для 100 000 отрезков, 50 000 окружностей и дополнительных серий. Для каждого запуска генерируются новые наборы, общие для сравниваемых алгоритмов. По завершении отображаются таблица, графики и два растра. Кнопка «Пример результатов» показывает сохранённые замеры и соответствующие им растры.
